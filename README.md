# ie0005-project

Dataset: [Cardiovascular Disease](https://www.kaggle.com/datasets/sulianova/cardiovascular-disease-dataset)

    Problem Statement: Can a machine-learning model using only non-invasive data screen for cardiovascular disease better than a simple clinical rule of thumb, and does it detect disease equally well across age and sex groups?
